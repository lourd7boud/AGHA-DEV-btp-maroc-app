# Changelog

All notable changes to BTP Desktop will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.2.0] - 2026-01-26

### Added
- 🎉 Initial release of BTP Desktop
- 📦 Multi-platform support (Windows, macOS, Linux)
- 💾 Native file save dialogs for PDF and Excel exports
- 🔄 Auto-update from GitHub Releases
- 🌐 Network status monitoring
- 📴 Offline mode support with sync queue
- 🔔 System tray icon
- 🖥️ Hardware acceleration for better performance

### Technical
- Electron 28.x with Vite build system
- electron-builder for multi-platform packaging
- electron-updater for auto-updates
- IPC bridge for secure main/renderer communication

## [Unreleased]

### Planned
